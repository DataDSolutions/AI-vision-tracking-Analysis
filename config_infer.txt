# 0.25: the alley cameras (camera2-ch801 / camera3-ch201) show standing and
# walking people at oblique angles in dim light, where the model's confidence is
# low. At 0.30 many of those real people fell below the bar and were never
# emitted, so multi-person alley scenes looked "empty" while the well-lit seated
# office male on camera4 detected on nearly every frame. 0.25 recovers more of
# those low-confidence real people. The app's fixture/motion guard suppresses the
# empty-chair/parked-bike false positives, so the detector bar no longer has to
# be high. If phantom NON-chair detections appear, raise back toward 0.30-0.35.
# 0.20 (was 0.25). The two people standing by the bikes on cam2-ch801 (image 2)
# were being emitted below 0.25 in the dim, oblique alley and never reached the
# tracker. 0.20 recovers them. This raises furniture false positives too, but
# the app's motion/persistence + ReID-fixture guard now suppresses those at the
# UID-commit gate, so the detector bar can afford to be low. If phantom NON-chair
# boxes appear, raise back toward 0.25.
